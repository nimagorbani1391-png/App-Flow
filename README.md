# APP FLOW

اپ فلو یک پلتفرم فارسی برای ساخت بصری رابط کاربری اپلیکیشن و وب‌اپلیکیشن است.

## امکانات فعلی

- داشبورد مدیریت چند پروژه: ساخت، بازکردن، جست‌وجو، کپی و حذف پروژه
- ویرایشگر بصری فارسی و راست‌چین با پیش‌نمایش زنده موبایل
- افزودن متن، دکمه، کادر ورودی و کارت
- انتخاب و مدیریت لایه‌ها و جابه‌جایی ترتیب آن‌ها با کشیدن یا دکمه‌های بالا/پایین
- ویرایش متن، رنگ متن، رنگ پس‌زمینه، اندازه متن، فاصله داخلی، گردی گوشه و تراز
- تغییر اندازه پیش‌نمایش بین موبایل، تبلت و دسکتاپ
- واگرد و ازنو با دکمه و میانبرهای صفحه‌کلید
- ذخیره خودکار و ذخیره دستی
- ذخیره محلی با IndexedDB و جایگزین LocalStorage در مرورگرهای ناسازگار
- مهاجرت داده‌های ذخیره‌شده در نسخه‌های قبلی تا حدی که ساختار آن‌ها قابل‌شناسایی باشد
- خروجی گرفتن از همه پروژه‌ها و بازیابی از فایل پشتیبان JSON
- نمایش خطاهای ذخیره‌سازی و پیام‌های موقت قابل‌دسترسی

## ذخیره‌سازی و حریم خصوصی

در نسخه فعلی، پروژه‌ها روی همان دستگاه و در همان مرورگر کاربر ذخیره می‌شوند. اطلاعات به‌صورت خودکار میان دستگاه‌ها همگام نمی‌شوند و با پاک‌کردن داده‌های سایت یا فضای مرورگر ممکن است از بین بروند؛ برای همین قابلیت پشتیبان‌گیری و بازیابی JSON در نظر گرفته شده است.

**ورود کاربر و ذخیره‌سازی ابری هنوز فعال نیست.** برای فعال‌سازی آن باید یک پروژه پایگاه داده مستقل برای App Flow provision شود، تنظیمات احراز هویت و سیاست‌های Row Level Security اعمال شوند و متغیرهای محیطی امن به فرایند استقرار اضافه شوند. پروژه Supabase مربوط به محصول دیگری نباید برای این کار استفاده شود.

## اجرا در محیط توسعه

```bash
npm install
npm run dev
```

## ساخت نسخه انتشار

```bash
npm run build
```

GitHub Actions پس از هر تغییر در شاخه اصلی، برنامه را می‌سازد و در صورت موفقیت در GitHub Pages منتشر می‌کند.

## محدودیت‌های فعلی

- خروجی مستقل Android APK / AAB یا بسته وب قابل انتشار تولید نمی‌شود.
- سیستم ورود، حساب کاربری و همگام‌سازی ابری راه‌اندازی نشده است.
- ابزارهای فعلی برای طراحی چیدمان و سبک‌های پایه هستند؛ موتور تولید اپلیکیشن و کامپایل خروجی هنوز ساخته نشده است.
- امنیت و مجوزدهی چندکاربره تا زمان راه‌اندازی بک‌اند مستقل قابل ارائه نیست.

## پیش‌نمایش چنداندازه‌ای
ویرایشگر دارای حالت‌های پیش‌نمایش موبایل، تبلت و دسکتاپ است. این حالت‌ها فقط قاب و اندازه پیش‌نمایش را تغییر می‌دهند و جایگزین تست روی دستگاه واقعی نیستند.
