# APP FLOW

APP FLOW یک پلتفرم تحت وب برای طراحی بصری اپلیکیشن‌های اندرویدی است. کاربران در این پلتفرم فقط اپلیکیشن Android طراحی می‌کنند؛ ساخت وب‌سایت توسط کاربران جزو محصول نیست.

## MVP فعلی
- داشبورد جدید با فضای کاری و قالب‌های شروع
- ایجاد پروژه از صفحه خالی یا قالب فروشگاهی، شخصی و خدماتی
- ویرایشگر بصری با پنل اجزا، فهرست لایه‌ها، پیش‌نمایش موبایل/تبلت و پنل ویژگی‌ها
- افزودن و حذف اجزا، تغییر ترتیب و انتخاب اجزا
- ویرایش متن، رنگ متن و زمینه، اندازه، فاصله داخلی، گردی گوشه و تراز
- ذخیره خودکار محلی با IndexedDB و fallback
- جست‌وجو، تکثیر، حذف و پشتیبان‌گیری/بازیابی JSON
- رابط فارسی RTL و واکنش‌گرا

## محدودیت‌های فعلی
- این نسخه وبِ پلتفرم APP FLOW است، نه خروجی اندرویدی خود پلتفرم.
- پروژه‌ها فعلاً روی همان مرورگر/دستگاه ذخیره می‌شوند؛ ورود کاربر و همگام‌سازی ابری وجود ندارد.
- موتور تولید و امضای APK/AAB و منطق اجرایی اپ‌های ساخته‌شده هنوز پیاده‌سازی نشده است.
- دکمه انتشار فعلاً فقط وضعیت آینده خروجی APK را اعلام می‌کند و فایل نصب تولید نمی‌کند.

## فناوری
React + TypeScript + Vite، ذخیره‌سازی محلی IndexedDB، GitHub و GitHub Actions.
