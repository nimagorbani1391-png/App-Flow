# APP FLOW

**APP FLOW یک اپلیکیشن اندرویدی برای ساخت اپلیکیشن‌های اندروید بدون کدنویسی است.**

هدف محصول این است که کاربر بتواند با یک ویرایشگر بصری، صفحه‌ها و اجزای اپلیکیشن خود را طراحی کند، رفتارهای پایه را تنظیم کند و در نهایت خروجی قابل نصب اندروید دریافت کند.

## جهت محصول

- پلتفرم اصلی و هدف انتشار: Android
- خروجی نهایی موردنظر: APK برای نصب و AAB برای انتشار در فروشگاه‌ها
- تجربه کاربری: ساده، روان، مینیمال و مناسب کاربران مبتدی
- زبان رابط: فارسی و راست‌چین
- طراحی بصری: تم تیره با آبی نئونی و جزئیات درخشان محدود؛ حس مدرن و تکنولوژیک، بدون شلوغی بصری
- منبع اصلی کد و مدیریت نسخه‌ها: GitHub

## وضعیت فنی فعلی — 2026-11-26

مخزن فعلی هنوز یک پروژه React + TypeScript + Vite است که برای اجرا در مرورگر ساخته شده است.

- کد فعلی Android native نیست.
- فایل‌های Gradle و پروژه Android در مخزن وجود ندارند.
- در وضعیت فعلی APK یا AAB ساخته نمی‌شود.
- گردش‌کار GitHub Actions فعلی فقط نسخه وب را در GitHub Pages منتشر می‌کند؛ این انتشار، خروجی اندروید محسوب نمی‌شود.
- نسخه Lovable مرجع توسعه نیست و نباید به‌عنوان محصول نهایی یا مبنای اصلی کد در نظر گرفته شود.

بنابراین کد فعلی یک نمونه اولیه مرورگری است و برای رسیدن به محصول موردنظر باید معماری و رابط کاربری به مسیر اندروید منتقل و بازطراحی شوند. تا زمان آماده‌شدن پروژه اندروید، نباید ادعا شود که APP FLOW خروجی APK/AAB دارد.

## مسیر توسعه

1. تثبیت معماری اندروید و انتخاب فناوری مناسب.
2. ایجاد پروژه واقعی Android و تنظیم ساخت Debug/Release.
3. پیاده‌سازی پوسته رابط کاربری با تم آبی نئونی، تیره و مینیمال.
4. ساخت داشبورد پروژه‌ها و ویرایشگر بصری.
5. ذخیره‌سازی پروژه‌ها روی دستگاه و پشتیبان‌گیری.
6. پیاده‌سازی موتور تولید اپلیکیشن و خروجی APK/AAB.
7. ساخت خودکار و آزمایش خروجی‌ها با GitHub Actions.

## محدودیت‌ها و اصول

- هدف محصول، اپلیکیشن اندرویدی است؛ وب‌سایت یا وب‌اپ خروجی نهایی نیست.
- هیچ سرویس پولی یا اشتراک جدیدی بدون تأیید صریح مالک پروژه فعال نمی‌شود.
- GitHub Pages صرفاً میزبان وب‌سایت است و برای ساخت یا میزبانی APK استفاده نمی‌شود.
- قابلیت‌های ابری، حساب کاربری و بک‌اند فقط پس از طراحی و انتخاب زیرساخت مستقل اضافه خواهند شد.
