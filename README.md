# APP FLOW
پلتفرم ساخت بصری اپلیکیشن و وب‌اپلیکیشن بدون کدنویسی.

## اجرای محلی
```bash
npm install
npm run dev
```

## ساخت نسخه انتشار
```bash
npm run build
```

## امکانات نسخه MVP
- ویرایشگر بصری فارسی و راست‌چین
- افزودن عنوان، متن، دکمه، تصویر، لینک و بخش
- ویرایش محتوا، رنگ، اندازه فونت، فاصله و تراز
- جابه‌جایی، کپی و حذف اجزا
- پیش‌نمایش دسکتاپ، تبلت و موبایل
- ذخیره خودکار روی دستگاه با localStorage
- ورود و خروجی گرفتن از پروژه به شکل JSON

## محدوده فعلی
این نسخه MVP ویرایشگر صفحه است؛ هنوز خروجی اپلیکیشن مستقل، حساب کاربری، فضای ابری، دیتابیس مرکزی و انتشار خودکار پروژه‌های کاربران را ارائه نمی‌کند. داده‌های پروژه در این مرحله روی دستگاه کاربر ذخیره می‌شوند.
