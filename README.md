# APP FLOW

**APP FLOW یک پلتفرم تحت وب برای طراحی بصری اپلیکیشن‌های اندرویدی است.**

کاربر در سایت APP FLOW پروژه می‌سازد و رابط اپ اندرویدی خودش را بدون کدنویسی طراحی می‌کند. ساخت وب‌سایت توسط کاربران جزو محصول نیست؛ خروجی نهایی موردنظر فقط اپلیکیشن Android است.

## MVP فعلی

- داشبورد مدیریت پروژه‌ها
- ایجاد، تغییر نام، جست‌وجو، تکثیر و حذف پروژه
- ویرایشگر بصری با اجزای پایه: متن، عنوان، دکمه، ورودی، کارت، تصویر، جداکننده، برچسب، چک‌باکس و فاصله‌گذار
- پیش‌نمایش واکنش‌گرا در اندازه موبایل، تبلت و دسکتاپ
- انتخاب، جابه‌جایی، تغییر اندازه و مرتب‌سازی لایه‌ها
- تنظیم متن، رنگ، اندازه، فاصله، ابعاد و تراز عناصر
- واگرد و انجام دوباره (Undo/Redo)
- ذخیره خودکار محلی در مرورگر با IndexedDB و fallback
- خروجی و بازیابی فایل پشتیبان JSON
- رابط فارسی RTL با تم تیره، آبی نئونی و طراحی مینیمال

## محدودیت‌های شفاف MVP

- این نسخه، وب‌سایت خود پلتفرم APP FLOW است؛ نه اپلیکیشن اندرویدی APP FLOW.
- کاربران فقط برای ساخت اپلیکیشن اندرویدی از پلتفرم استفاده می‌کنند؛ ابزار ساخت سایت ارائه نمی‌شود.
- پروژه‌ها فعلاً روی همان دستگاه/مرورگر ذخیره می‌شوند؛ حساب کاربری، همگام‌سازی ابری و دیتابیس سرور هنوز پیاده‌سازی نشده‌اند.
- ویرایشگر فعلی نمونه اولیه طراحی رابط است. خروجی APK/AAB، کامپایلر پروژه‌های کاربر، منطق اجرایی اپ‌ها، امضای انتشار و انتشار در فروشگاه هنوز پیاده‌سازی نشده‌اند.
- بنابراین در این مرحله نباید ادعا شود که کاربر می‌تواند APK/AAB نهایی دریافت کند.

## اجرا و انتشار

- فناوری فعلی: React + TypeScript + Vite
- مخزن کد: GitHub
- انتشار نسخه وب MVP: GitHub Pages از طریق GitHub Actions
- مسیر انتشار فعلی: `https://nimagorbani1391-png.github.io/App-Flow/`

## نقشه راه

1. تکمیل و تست تجربه طراحی در MVP وب
2. طراحی مدل داده و ساختار واقعی پروژه اندرویدی خروجی
3. پیاده‌سازی موتور تولید Android APK/AAB و قالب/runtime امن
4. ساخت pipeline کامپایل، امضا و اعتبارسنجی خروجی‌ها
5. افزودن حساب کاربری و ذخیره‌سازی ابری در صورت نیاز محصول

هیچ سرویس یا اشتراک پولی بدون تأیید صریح مالک پروژه فعال نمی‌شود.
